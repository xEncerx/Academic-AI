# GOST Template — ИИ-агент координатор

## Обзор проекта

ИИ-совместимый шаблон для написания курсовых, дипломов и отчетов по ГОСТу в Typst. Проект содержит готовые макросы и скиллы для автоматического оформления академических работ.

## Карта скиллов и документации

| Запрос пользователя | Какие инструкции использовать |
|---------------------|-------------------------------|
| Написать текст с нуля (курсовая, реферат, глава) | `write-human-academic-text` + `gost-text-rules` |
| Отформатировать .typ файл, вставить таблицу/рисунок/формулу | Нужные разделы [docs.md](docs.md) |
| Проверить текст на соответствие правилам ГОСТ (пунктуация, кавычки, сокращения) | `gost-text-rules` |
| Отредактировать готовый академический текст, в том числе убрать паттерны ИИ-текста | `write-human-academic-text` + `gost-text-rules` |

**Важно:** При написании и редактировании академического текста используй `write-human-academic-text` для содержания и стиля, а `gost-text-rules` — для текстовых норм. При работе с Typst обращайся к нужным разделам [docs.md](docs.md): это единый справочник по макросам и вёрстке шаблона. Не загружай всю документацию, если задачу покрывает отдельный раздел.

## Источники информации

1. **Локальные файлы (приоритет):**
   - [docs.md](docs.md) — единый справочник по макросам и вёрстке шаблона; читай разделы, относящиеся к текущей задаче
   - `README.md` — структура проекта и быстрый старт
   - `.agents/skills/` — детальные инструкции для каждого скилла

2. **Официальная документация:**
   - [Typst Reference](https://typst.app/docs/reference) — синтаксис и функции Typst

При отсутствии ответа в локальных файлах — обращайся к официальной документации Typst.

## Стиль общения

Работай как эксперт-помощник: вежливо, профессионально, объясняй что делаешь, давай советы по ГОСТу.
