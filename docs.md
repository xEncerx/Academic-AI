# Правила использования шаблона ГОСТ

Документ описывает функции и макросы шаблона Typst, а также правила их применения при верстке.

## Шрифты

Для основного текста шаблон сначала использует Times New Roman, а при отсутствии этой гарнитуры — встроенный Liberation Serif. Для листингов аналогично используются Courier New и резервный Liberation Mono. При сборке из терминала подключите каталог шрифтов:

```bash
typst compile --font-path settings/fonts main.typ main.pdf
```

Tinymist получает тот же каталог из `.vscode/settings.json`.

## Основной стиль (`gost-core.typ`)

### Инициализация документа

Функция `gost-core` задает базовые настройки страницы (формат А4, поля), нумерацию, абзацные отступы (1,25 см), полуторный интервал, а также форматирование заголовков и списков.

**Пример вызова в `main.typ`:**

```typst
#import "settings/gost_core.typ": gost-core

#show: gost-core

= НАЗВАНИЕ ГЛАВЫ
Текст главы...

== Подраздел
Текст подраздела...

- Элемент маркированного списка;
- Второй элемент.

+ Элемент нумерованного списка.
+ Второй элемент.
```

### Автоматическое форматирование

При подключении `gost-core` применяются следующие правила:

1. **Параметры страницы:** Формат А4 с полями (левое — 30 мм, правое — 10 мм, верхнее и нижнее — 20 мм). Нумерация сквозная, а отображение номеров страниц начинается со страницы, следующей за меткой `<start-numbering>`.
2. **Заголовки:**
   - **Уровень 1 (`=`):** Начинаются с новой страницы. Шрифт 18 pt, полужирный, все буквы прописные. Номер выводится без точки в конце (например, `1 НАЗВАНИЕ`). Абзацный отступ — 1,25 см.
   - **Уровень 2 (`==`):** Шрифт 16 pt, полужирный. Интервалы до и после текста составляют 15 мм и 10 мм соответственно. Номер оканчивается точкой (`1.1. Название`).
   - **Уровни 3 и ниже (`===`):** Шрифт 14 pt, полужирный.
3. **Основной текст:** Гарнитура Times New Roman, размер 14 pt, выравнивание по ширине. Отступ первой строки установлен на 1,25 см, межстрочный интервал — полуторный.
4. **Списки:** Для маркированных списков (`-`) используется символ `●`, для нумерованных (`+`) — арабские цифры без точки. Отступ маркера или цифры равен 1,25 см, текст начинается на расстоянии 2,25 см от левого края.

> **Важно:** Инструменты Typst управляют отступами, однако пунктуацию и регистр слов автор контролирует самостоятельно. Маркированный список принято начинать со строчной буквы и завершать точкой с запятой. Нумерованный список начинается с прописной буквы и оканчивается точкой.

### Начало отображения номеров страниц

Титульный лист и содержание входят в сквозную нумерацию, но номер на них не печатается. Метка `<start-numbering>` указывает последнюю страницу без видимого номера: нижний колонтитул появляется со следующей страницы. Поэтому метку размещают после всего содержания и непосредственно перед основным текстом:

```typst
// Для PDF-варианта предварительно добавьте свой файл в assets:
#gost-title(path: "/assets/title_page.pdf")
#show: gost-core

#include "chapters/01_toc.typ"
#metadata("start-numbering") <start-numbering>
#include "chapters/02_main_text.typ"
```

Если перед основным текстом добавлены другие ненумеруемые страницы, их также следует подключить до метки. Не переносите `<start-numbering>` перед содержанием: иначе номера появятся на его страницах.

### Заголовки первого уровня и счетчики объектов

При `chapter-numbering: true` каждый заголовок первого уровня сбрасывает счетчики рисунков и листингов. Нумерованный заголовок `= РАЗДЕЛ` одновременно увеличивает номер раздела, поэтому далее формируются номера вида «Рисунок 2.1» и «Листинг 2.1».

Ненумерованный заголовок `#heading(level: 1, numbering: none)[ЗАКЛЮЧЕНИЕ]` также сбрасывает счетчики, но не увеличивает номер раздела. Рисунок или листинг после него может повторить номер последнего раздела. Поэтому не размещайте нумеруемые объекты после ненумерованных заголовков первого уровня либо используйте для содержащего их раздела нумерованный заголовок. То же правило действует для таблиц и формул.

## Оформление рисунков (`gost_figures.typ`)

Модуль `gost-figures` приводит отображение иллюстраций в соответствие с требованиями ГОСТа. Номера генерируются автоматически, перед названием подставляется слово «Рисунок» и длинное тире. Разрыв рисунка и его подписи между страницами заблокирован.

### Вставка рисунка

Для размещения иллюстраций применяется стандартная функция Typst `#figure()`, поскольку она корректно интегрируется с механизмами нумерации и перекрестных ссылок.

По умолчанию включена сквозная нумерация. Если требуется нумерация по разделам (формата 1.1, где первая цифра обозначает главу, а вторая — порядковый номер рисунка внутри нее), необходимо передать параметр `chapter-numbering: true`.

```typst
// Сквозная нумерация (по умолчанию)
#import "settings/gost_figures.typ": gost-figures
#show: gost-figures

// Нумерация по разделам (Глава.Рисунок)
#import "settings/gost_figures.typ": gost-figures
#show: gost-figures.with(chapter-numbering: true)

// Вставка изображения
#figure(
  image("/assets/images/photo.jpg", width: 80%),
  caption: [Детали прибора]
) <img-details>
```
*Результат под изображением: **Рисунок 1 — Детали прибора*** (без точки в конце, шрифт Times New Roman, 12 pt, полужирный, выравнивание по центру).

### Временный рисунок без файла

Если изображение еще не подготовлено или недоступно ИИ-ассистенту, используйте `#gost-image-placeholder`. Макрос выводит нейтральный серый блок, но учитывается как обычный рисунок: получает номер и подпись, поддерживает метки и перекрестные ссылки.

```typst
#import "settings/gost_figures.typ": gost-image-placeholder

#gost-image-placeholder(
  caption: [Схема взаимодействия компонентов],
  width: 80%,
  height: 55mm,
  note: [Здесь будет схема взаимодействия компонентов],
) <img-components>
```

Параметры `width`, `height` и `note` необязательны. Когда готовый файл появится, замените вызов макроса на стандартный рисунок, сохранив подпись и метку:

```typst
#figure(
  image("/assets/images/components.png", width: 80%),
  caption: [Схема взаимодействия компонентов],
) <img-components>
```

### Ссылки на рисунки в тексте

Перекрестные ссылки создаются с помощью встроенной функции `#ref()`. Typst распознает тип объекта и автоматически генерирует нужное слово с номером:

```typst
В соответствии с @img-details можно заметить...
// Вывод: В соответствии с Рисунок 1 можно заметить...

// Для изменения падежа передается аргумент supplement:
В соответствии с #ref(<img-details>, supplement: "Рисунком") можно заметить...
// Вывод: В соответствии с Рисунком 1 можно заметить...
```

### Альбомная ориентация 

Для размещения широких графиков страницу необходимо повернуть. По ГОСТу это достигается переходом в альбомную ориентацию:

```typst
#page(flipped: true)[
  #figure(
    image("/assets/images/wide_chart.jpg", width: 100%),
    caption: [Широкий график]
  ) <img-wide>
]
```

## Оформление формул (`gost_math.typ`)

Модуль отвечает за верстку математических выражений. Формулы нумеруются по правому краю в круглых скобках, а для расшифровки переменных предусмотрен специальный макрос.

```typst
#import "settings/gost_math.typ": gost-math, gost-where
#show: gost-math.with(chapter-numbering: true)
```

### Формулы и нумерация

По умолчанию нумеруются все вынесенные в отдельный блок формулы. Размер символов вычисляется автоматически на основе базового шрифта 14 pt.

```typst
Формула с номером:
$ Delta T = T_0 - T_1, $ <eq-trud>

По правилам нумеровать следует только те формулы, на которые есть ссылки в тексте.
Для отключения номера используйте локальную настройку:
#block[
  #set math.equation(numbering: none)
  $ A = B + C $
]
```

### Перекрестные ссылки на формулы

Для вызова номера в тексте применяется `#ref()`. Макрос самостоятельно обернет номер в круглые скобки:

```typst
Расчет производится по формуле @eq-trud.
// Вывод: Расчет производится по формуле (7.1).
```

### Пояснения к переменным

Список значений символов оформляется макросом `gost-where`. Каждая переменная передается как массив из двух элементов `(символ, [описание])`. Макрос добавляет слово «где», проставляет тире и выравнивает текст без абзацного отступа.

```typst
$ Delta T = T_0 - T_1, $ <eq-trud>
#gost-where(
  ($T_0$, [трудовые затраты на обработку информации по базовому варианту;]),
  ($T_1$, [трудовые затраты на обработку информации по предлагаемому варианту.])
)
```

> **Важно:** Следите за знаками препинания. Запятая ставится после формулы, точка с запятой — между элементами списка пояснений, точка — в конце. При переносе длинного математического выражения на новую строку знаки равенства или арифметических операций дублируются вручную: `$ a = b + c + \ + d $`

## Оформление таблиц (`gost_tables.typ`)

Модуль `gost-tables` автоматизирует форматирование табличных данных. Он обеспечивает выравнивание подписи над таблицей (`Таблица 1.1 — Название`, шрифт 12 pt, по левому краю) и устанавливает одинарный интервал для содержимого без абзацных отступов. Заголовки столбцов центрируются и выделяются полужирным начертанием, в то время как обычные ячейки выравниваются по левому краю.

При разрыве таблицы на следующую страницу макрос переносит заголовки и автоматически добавляет надпись вида *«Продолжение Таблицы N»* в правом верхнем углу.

```typst
#import "settings/gost_tables.typ": gost-tables, gost-table
#show: gost-tables.with(chapter-numbering: true)
```

### Использование макроса `#gost-table`

Для таблиц, занимающих более одной страницы, применяется функция `#gost-table`. 

**Основные параметры:**
- `columns`: Ширина столбцов в виде массива (допускаются значения `auto` или `1fr`).
- `caption`: Название таблицы.
- `header`: Массив заголовков столбцов.
- `..cells`: Данные ячеек.

```typst
#gost-table(
  columns: (1fr, 2fr, 2fr),
  caption: [Анализ параметров],
  header: ([Параметр], [Значение 1], [Значение 2]),
  [Шрифт], [Times New Roman], [Arial],
  [Интервал], [Обычный], [Полуторный]
) <tab-analysis>
```

> **Особенности:** На данный момент механизм Typst сохраняет нижнюю рамку таблицы при ее разрыве в конце страницы. Текст *«Продолжение Таблицы N»* формируется автоматически. Выравнивание заголовков строк и данных в графах при необходимости корректируется вручную.

## Листинги программного кода (`gost_listings.typ`)

Исходный код оформляется с обводкой тонкой черной рамкой и моноширинным шрифтом (Courier New, 10 pt). Подпись располагается над блоком (12 pt, курсив, выравнивание по левому краю). Для ссылок на фрагменты кода требуется нумерация строк с шагом 10.

```typst
#import "settings/gost_listings.typ": gost-listings, gost-listing
#show: gost-listings.with(chapter-numbering: true)
```

### Вставка листинга

Функция `#gost-listing()` считывает код из внешнего файла или напрямую из строки. По умолчанию номера строк не выводятся; для их включения передайте `numbers: true`.

**Параметры:**
- `file`: Путь к исходному файлу (например, `"/assets/codes/script.py"`).
- `code`: Строка с кодом (если файл не используется).
- `caption`: Название блока.
- `lang`: Язык для подсветки синтаксиса (опционально).
- `numbers`: По умолчанию `false`. При значении `true` выводит номера строк слева (`10, 20, 30...`).
- `new-page`: При `true` переносит листинг на новую страницу (часто используется для приложений).

**Пример вставки из файла:**
```typst
#gost-listing(
  file: "/assets/codes/main.py",
  caption: [Скрипт запуска],
  lang: "python",
  numbers: true
) <list-main>
```

### Ссылки на строки

Для указания конкретных строк в тексте номера перечисляются в фигурных скобках после метки:

```typst
В @list-main {30, 50, 140} показаны основные вызовы.
Как видно из @list-main {20-80}, алгоритм...
```
*(Результат: «В Листинг 1.7 {30, 50, 140} показаны...»)*

## Титульный лист

Титульник можно сформировать из заполненных полей или вставить готовым PDF. Выберите один способ и вызовите соответствующий макрос в начале `main.typ`, до `#show: gost-core`. Оба варианта создают отдельную страницу без видимого номера; она учитывается в сквозной нумерации документа.

### Создание титульника из полей (`gost_title.typ`)

Макрос `gost-title-page` воспроизводит компоновку титульника РТУ МИРЭА: герб и сведения об организации сверху, название работы и дисциплина по центру, строки студента и преподавателя с датами и местами для подписей ниже, город и год внизу.

```typst
#import "settings/gost_title.typ": gost-title-page

#gost-title-page(
  title: [ОТЧЁТ ПО ПРАКТИЧЕСКОМУ ЗАНЯТИЮ № 2],
  discipline: [Проектирование информационных систем],
  group: [БСБО-99-26],
  student: [Примеров А. Б.],
  teacher: [Образцова В. Г.],
)

#show: gost-core
```

Поля `title`, `discipline`, `group`, `student` и `teacher` обязательны: если поле не задано или пусто, компиляция завершится ошибкой с его названием. Название работы передаётся целиком, включая её вид и номер.

#### Даты и год

Typst получает текущую дату через [`datetime.today()`](https://typst.app/docs/reference/foundations/datetime/#definitions-today). По умолчанию обе строки подписей содержат дату компиляции, а нижняя строка — текущий год. Поэтому при каждом вызове макроса заполнять даты не требуется.

| Параметр | Значение по умолчанию и назначение |
|----------|-----------------------------------|
| `date` | `datetime.today()` — общая дата для студента и преподавателя. |
| `student-date` | `auto` — использовать `date`; можно указать отдельную дату студента. |
| `teacher-date` | `auto` — использовать `date`; можно указать отдельную дату преподавателя. |
| `year` | `datetime.today().year()` — год внизу страницы; задаётся независимо от дат подписей. |
| `date-format` | Функция оформления даты: для `datetime` выводит «03» марта 2026 г.; строки и готовый Typst-контент оставляет без изменений. |

Для фиксированных дат передайте `datetime(year: 2026, month: 3, day: 3)`. Параметр `date` задаёт сразу обе даты, а `student-date` и `teacher-date` имеют приоритет для соответствующей строки. Если меняете год работы, укажите также `year`, чтобы он не зависел от текущего года.

#### Сведения об организации и подписи

Текстовые поля принимают строки или Typst-контент. Значения по умолчанию соответствуют образцу РТУ МИРЭА и могут быть заменены.

| Параметр | Значение по умолчанию |
|----------|----------------------|
| `ministry` | МИНОБРНАУКИ РОССИИ. |
| `university-type` | Федеральное государственное бюджетное образовательное учреждение высшего образования. |
| `university` | «МИРЭА — Российский технологический университет». |
| `university-short` | РТУ МИРЭА. |
| `institute` | Институт кибербезопасности и цифровых технологий. |
| `department` | Кафедра КБ-9 «Предметно-ориентированные информационные системы». |
| `city` | Москва. |
| `emblem` | `"/assets/images/mirea-emblem.png"` — герб из комплекта шаблона; `none` скрывает изображение. |
| `discipline-label` | «по дисциплине» — подпись перед названием дисциплины в кавычках. |
| `report-note` | «Отчёт представлен к рассмотрению:», разбитое на две строки. |
| `student-label` | «Студент группы» — перед номером группы. |
| `teacher-label` | «Преподаватель». |
| `signature-caption` | «(подпись)» — под каждой линией подписи. |
| `footer` | `auto` — город и год; можно передать своё содержимое нижней строки или `none`, чтобы скрыть её. |

Для скрытия отдельных строк организации передайте `none` в `ministry`, `university-type`, `university`, `university-short`, `institute` или `department`. `report-note: none` убирает вводную надпись перед подписями.

Пример настройки для другой организации, с вымышленными данными и фиксированными датами:

```typst
#gost-title-page(
  title: [ОТЧЁТ ПО ПРАКТИЧЕСКОМУ ЗАНЯТИЮ № 5],
  discipline: [Основы моделирования],
  group: [УЧ-01-26],
  student: [Примерова А. Б.],
  teacher: [Образцов В. Г.],
  ministry: none,
  university-type: none,
  university: [Учебный университет «Пример»],
  university-short: none,
  institute: [Институт моделирования],
  department: [Кафедра учебных систем],
  emblem: none,
  city: [Учебный город],
  date: datetime(year: 2026, month: 3, day: 3),
  teacher-date: datetime(year: 2026, month: 3, day: 5),
  year: 2026,
)
```

#### Параметры оформления

| Параметр | По умолчанию |
|----------|--------------|
| `paper` | `"a4"`. |
| `margin` | `(top: 20mm, bottom: 30mm, left: 30mm, right: 10mm)`. |
| `font` | Times New Roman с резервным Liberation Serif. |
| `font-size` | `12pt` — вводная надпись перед подписями, роли, группа, даты и имена. |
| `header-size` | `11pt` — министерство. |
| `institution-size` | `12pt` — тип и название вуза, институт и кафедра. |
| `university-short-size` | `16pt` — краткое название вуза. |
| `title-size`, `discipline-size` | `16pt`, `14pt` — название работы и строка дисциплины. |
| `footer-size`, `signature-caption-size` | `14pt`, `11pt` — город с годом и пояснения под подписями. |
| `emblem-height`, `emblem-gap` | `30mm`, `2mm` — высота герба и отступ после него. |
| `header-line-gap` | `1mm` — отступ между блоками текста шапки. |
| `institution-gap` | `9mm` — отступ перед институтом и кафедрой. |
| `title-gap`, `signatures-gap` | `25mm`, `28mm` — отступы перед названием работы и блоком подписей. |
| `note-gap` | `1mm` — отступ после вводной надписи перед подписями. |
| `signature-row-gap` | `12mm` — расстояние между строками студента и преподавателя. |
| `signature-columns` | `(1.8fr, 1.25fr, 1fr, 1fr)` — ширины колонок «роль и группа / дата / подпись / имя». |
| `signature-column-gutter` | `3mm` — расстояние между колонками. |
| `signature-stroke` | `0.5pt` — толщина линий для подписей. |

При длинных названиях или другом формате бумаги подберите размеры шрифта, отступы и ширины колонок, чтобы титульник помещался на одной странице.

### Вставка готового PDF (`gost_intro_frame.typ`)

Добавьте свой PDF в `assets` и укажите путь в `gost-title`.

```typst
#import "settings/gost_intro_frame.typ": gost-title

#gost-title(path: "/assets/my_title.pdf")
#show: gost-core
```

`gost-title` размещает изображение первой страницы PDF на отдельной странице без полей и колонтитулов. Вызов `gost-title()` без аргументов ищет `"/assets/title_page.pdf"` — для этого самостоятельно добавьте файл по данному пути. Чтобы совсем убрать титульник, удалите его вызов из `main.typ`, а не только файл.

## Содержание (`gost_intro_frame.typ`)

```typst
#import "settings/gost_intro_frame.typ": gost-toc
```

### Генерация содержания

Оглавление собирается из заголовков трех верхних уровней. Слово «СОДЕРЖАНИЕ» печатается шрифтом 18 pt, полужирным начертанием, без нумерации и выравнивается по центру. Заголовки первого уровня автоматически переводятся в верхний регистр.

```typst
#gost-toc()
```

> **Перенос строк:** Если название пункта перекрывает номера страниц в содержании, разрыв строки `\ ` проставляется вручную в самом заголовке по тексту документа. Typst автоматически перенесет это форматирование в оглавление.

## Список использованных источников (`gost_references.typ`)

Оформление библиографии с разбивкой по категориям (Аналитический, Специальный разделы) и составной нумерацией реализуется через набор макросов.

```typst
#import "settings/gost_references.typ": gost-bibliography-title, gost-bib-section
```

### Разделы списка

1. Вызов `#gost-bibliography-title()` формирует новую страницу с отцентрированным заголовком «СПИСОК ИСПОЛЬЗОВАННЫХ ИСТОЧНИКОВ».
2. Функция `#gost-bib-section("Название")` создает подзаголовок раздела с нужными отступами и номером.
3. Ф-ция `gost-bib-item([Название])` создает Пункт библиографию раздела с нужным номером.

```typst
#gost-bibliography-title()

#gost-bib-section("Аналитический раздел") // Автоматически получит номер 1

#gost-bib-item([Борзенко А. и др. Компьютерная азбука \// Компьютер-пресс. --- 2006. --- № 11. --- С. 124--130.]) // Автоматически получит номер 1.1

#gost-bib-section("Специальный раздел") // Автоматически получит номер 2

#gost-bib-item([Надарая Э. А. Об оценке регрессии \// Теория вероятностей и ее применения. --- 2000. --- Т. 9. --- Вып. 1. --- С. 157--159.]) // Автоматически получит номер 2.1
```

Сами элементы списка верстаются обычными абзацами — базовые настройки стиля обеспечат правильный отступ первой строки и выравнивание. Внутритекстовые ссылки оформляются вручную в квадратных скобках: `[1.2, с.21-25]`.

> **Пунктуация:** Не ставьте пробелы после знаков препинания в сокращениях городов (например: `М.:` или `СПб.:`), а также между инициалами (`Иванов И.И.`). Для разделения областей библиографической записи используется длинное тире `—`.

## Приложения (`gost_appendix.typ`)

Приложения группируются в конце документа. Они перечисляются на отдельной странице, нумеруются буквами (Приложение А, Приложение Б) и имеют собственные счетчики для внутренних объектов (Рисунок А.1).

```typst
#import "settings/gost_appendix.typ": gost-appendix-list, gost-appendix
```

### Перечень и структура

Страница-перечень создается макросом `#gost-appendix-list`. В него передаются кортежи с буквой и названием.

```typst
#gost-appendix-list(
  ("А", "Техническое задание"),
  ("Б", "Листинги исходного кода")
)
```

Каждое приложение оборачивается в функцию `#gost-appendix`. При ее вызове счетчики таблиц, рисунков и листингов сбрасываются и адаптируются под буквенную нумерацию.

```typst
#gost-appendix("А", "Техническое задание")[
  Текст технического задания.

  #figure(image("scheme.png"), caption: [Схема]) <img-a>
  // Результат: "Рисунок А.1 — Схема"
]
```
