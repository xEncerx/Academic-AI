# 📝🎓 Academic-AI: Typst шаблон для написания отчетов/дипломов/курсовых работ(ИИ совместимый)

Готовый шаблон, который оформлен по требованиям [РТУ МИРЭА](./assets/Методические%20указания%20по%20оформлению%20работ.pdf)

## 📦 Установка Typst

Для работы с шаблоном вам понадобится [Typst](https://github.com/typst/typst).

<details>
<summary>🪟 Windows</summary>

### Установка на Windows

Выполните команду в PowerShell или CMD:

```powershell
winget install --id Typst.Typst
```

</details>

<details>
<summary>🐧 Linux</summary>

### Установка на Linux

Выполните команду в терминале:

```bash
curl -fsSL https://typst.community/typst-install/install.sh | sh
```

</details>

<details>
<summary>🍎 macOS</summary>

### Установка на macOS

Выполните команду в терминале:

```bash
brew install typst
```

</details>

## ✍️ Написание работы

Работу можно написать двумя способами: **вручную** или с помощью **ИИ-ассистента**.

### Вариант 1: Вручную

Если вы предпочитаете писать самостоятельно:

1. **Изучите документацию:**
   - [Документация по шаблону ГОСТ](./docs.md) — подробная инструкция по использованию макросов, вставке таблиц, рисунков и формул.
   - [Официальная документация Typst](https://typst.app/docs/reference) — полный справочник по синтаксису.

2. **Отредактируйте необходимые файлы:**
   - `chapters/02_main_text.typ` — основной текст работы
   - `chapters/03_references.typ` — список литературы
   - `chapters/04_appendix.typ` — приложения (если нужны)
   - Добавьте изображения в `/assets/images/`
   - Добавьте код в `/assets/codes/`

3. **Настройте титульный лист:**
   - В `main.typ` заполните поля `gost-title-page`: название работы, дисциплину, группу, имя студента и преподавателя. В демо используются вымышленные данные; даты и год по умолчанию текущие.
   - Для готового PDF добавьте свой файл в `assets` и замените вызов на `gost-title(path: "/assets/my_title.pdf")`, импортировав `gost-title` из `settings/gost_intro_frame.typ`.
   - Если титульный лист не нужен — удалите его вызов из `main.typ`.
   - Оба способа и параметры описаны в [документации](./docs.md#титульный-лист).

### Вариант 2: С помощью ИИ

Инструкции для ИИ-агента собраны в [AGENTS.md](./AGENTS.md): скиллы отвечают за содержание, стиль и текстовые нормы, а [docs.md](./docs.md) — за макросы и вёрстку Typst. Опишите задачу; агент выберет соответствующие скиллы и нужные разделы документации.

**Доступные скиллы:**

- `write-human-academic-text` — написание и редактирование академического текста, в том числе устранение типичных паттернов ИИ-текста
- `gost-text-rules` — проверка и соблюдение правил ГОСТ при написании текста (пунктуация, кавычки, сокращения, оформление списков и ссылок)

## 🚀 Быстрый старт

1. **Установите Typst** (см. раздел [Установка](#-установка-typst))

2. (Опционально) Для удобной работы с проектом, установите `Vs code` и расширение `Tinymist Typst`

3. **Склонируйте/скопируйте шаблон:**

   ```bash
   git clone https://github.com/xEncerx/Academic-AI
   cd Academic-AI
   ```

4. **Начните писать!**
   - Вручную — редактируйте файлы в `chapters/`
   - Или вызовите ИИ-агента и описывайте, что нужно добавить

5. **Скомпилируйте PDF:**
   ```bash
   typst compile --font-path settings/fonts main.typ main.pdf
   ```

## 🔤 Шрифты

Шаблон использует системные Times New Roman и Courier New, если они доступны. Если этих гарнитур нет, Typst автоматически применяет встроенные аналоги:

- Liberation Serif вместо Times New Roman;
- Liberation Mono вместо Courier New.

Файлы шрифтов находятся в `settings/fonts/` и распространяются по лицензии SIL Open Font License 1.1. Конфигурация `.vscode/settings.json` автоматически подключает их для предпросмотра и экспорта через Tinymist. При сборке из терминала передавайте `--font-path settings/fonts`, как показано выше.

## 🔄 Обновление шаблона

> Обновляются только файлы шаблона (`settings/`, `main.typ`, `.agents/` и т.д.).
> Ваши файлы в `chapters/` и `/assets/` **не затрагиваются**.

